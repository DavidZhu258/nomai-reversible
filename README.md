# Nomai Reversible

[中文](#中文) | [English](#english)

Fan-made reversible Nomai-style spiral writing for Unicode text. The project turns text into an SVG inspired by *Outer Wilds* Nomai wall writing and can decode its own generated SVG/token back to the exact original text.

![Nomai sample](examples/hello.svg)

> This is not an official Outer Wilds or Mobius Digital project. It is a free, open-source fan tool inspired by the visual language of the game and by the open-source [NomaiText.jl](https://github.com/evanfields/NomaiText.jl) project.

## 中文

### 项目介绍

Nomai Reversible 是一个可逆的 Nomai 风格文字生成器。它可以把中文、英文、日文、emoji 等任意 Unicode 文本编码成类似 *Outer Wilds* 游戏中 Nomai 螺旋墙文的 SVG 图像，并且可以从本工具生成的 SVG 或 `NOMAI1-*` token 精确解码回原文。

这个项目的视觉目标是尽量贴近 `NomaiText.jl` 的生成结果：使用 NomaiText.jl 风格的三行 glyph grid、polygon glyph、annotation、Luxor logarithmic spiral 和 `PathGridLayout` 排版规则。为了保证网页体验流畅，当前实现是 TypeScript 端口，不需要安装 Julia。

### 特性

- **完全可逆**：生成的 SVG 内嵌 metadata/token，decoder 可以恢复原始 Unicode 文本。
- **多语言输入**：视觉 oracle 默认使用 `base=200000`，适合常见 Unicode 文本。
- **NomaiText.jl 风格**：使用上游 `draw_spiral` 思路、log spiral、glyph grid、外圈 glyph 逐渐变大。
- **碰撞保护**：通过全局增加 spiral period 和安全连接点选择减少/避免线段重叠。
- **Web + CLI**：提供 Vite/React Web 界面，也支持命令行生成和解码。
- **开源可改**：MIT License，可 fork、修改、二次开发。

从 token 解码：


### Web 解码方式

1. 在左侧输入任意语言文本并生成 Nomai SVG。
2. 点击 `Download SVG` 保存，或点击 `Copy SVG` / `Copy Token`。
3. 在右侧粘贴 SVG、粘贴 `NOMAI1-*` token，或上传 `.svg` 文件。
4. 点击 `Decode Input` 或 `Decode Current`，恢复原始文本。

### Original text 和 English reading

- `Text to encode and decode` 是真正参与图像生成和可逆解码的文本。
- `English reading metadata` 只是可选的英文读音/翻译备注，会存入 metadata，但不会改变 Nomai 图像。

### 工作原理

1. 原始文本被保存到稳定 JSON envelope。
2. envelope 被编码成 `NOMAI1-*` token，并带 CRC32 checksum。
3. 原始文本同时被转换成大整数 oracle，驱动 Nomai glyph、grid 位置和连接点。
4. grid 被排到 Luxor 风格 logarithmic spiral 上，生成 SVG。
5. decoder 从 SVG metadata 或 token 中恢复 envelope，从而恢复原始文本。

### 限制

- 只保证本工具生成的 SVG/token 可逆；不支持从任意截图或 PNG OCR 回原文。
- 这不是官方 Nomai 语言，也不是游戏内真实可翻译文字系统。
- SVG 是主要输出格式；普通字体/输入法无法直接排出完整螺旋结构。

### 路线图

- 改进视觉密度和长文本布局。
- 增加更多示例和视觉回归测试。
- 探索线性 Nomai token 字体与 Keyman 输入法资源。
- 可选接入开源翻译/音标工具，用于 English reading metadata。

## English

### What Is This?

Nomai Reversible is a reversible Nomai-style writing generator. It converts arbitrary Unicode text, including Chinese, English, Japanese, emoji, and mixed-language text, into an SVG inspired by the Nomai spiral writing in *Outer Wilds*. SVGs generated by this tool can be decoded back to the exact original text.

The visual target is the open-source `NomaiText.jl` style: three-row glyph grids, polygon glyphs, annotations, a Luxor-like logarithmic spiral, and `PathGridLayout`-style scaling and spacing. This implementation is written in TypeScript, so the web app and CLI do not require Julia at runtime.

### Features

- **Reversible by design**: generated SVGs embed metadata/token data that round-trips to the original Unicode text.
- **Unicode-friendly**: the visual oracle defaults to `base=200000`, suitable for common Unicode input.
- **NomaiText.jl-inspired renderer**: log spiral layout, glyph grid placement, polygon glyphs, annotations, and outward scale growth.
- **Collision-aware layout**: global spiral period growth and safe connector endpoint selection reduce or avoid overlaps.
- **Web and CLI**: use the Vite/React web UI or the command-line encoder/decoder.
- **Open source**: MIT licensed and ready to fork, modify, and extend.

### Web Decoding

1. Enter any source-language text on the left.
2. Download the SVG, copy the SVG, or copy the `NOMAI1-*` token.
3. Paste the SVG/token or upload the `.svg` file on the right.
4. Click `Decode Input` or `Decode Current` to recover the original text.

### Original Text vs English Reading

- `Text to encode and decode` is the canonical source for both the visible Nomai geometry and decoder output.
- `English reading metadata` is optional pronunciation/translation metadata. It is stored but does not affect the visible Nomai geometry.

### How It Works

1. The source text is stored in a stable JSON envelope.
2. The envelope is encoded into a `NOMAI1-*` token with a CRC32 checksum.
3. The source text is also converted into a large integer oracle that drives glyph choice, grid placement, and connector choices.
4. The glyph grid is typeset onto a Luxor-like logarithmic spiral and rendered as SVG.
5. The decoder reads the SVG metadata or token stream and restores the original envelope and text.

### Limitations

- Reversibility applies to SVG/token output generated by this project; arbitrary screenshots or PNGs are not OCR-decoded.
- This is not an official Nomai language or a canonically translatable in-game writing system.
- SVG is the main output. A normal font or keyboard cannot directly typeset full spiral writing.

### Roadmap

- Improve visual density and long-text composition.
- Add more curated examples and visual regression tests.
- Explore linear Nomai token fonts and Keyman keyboard assets.
- Optionally integrate open-source translation or phonemization tools for English reading metadata.
